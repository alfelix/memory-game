# Игра "Найди пару" (Memory Game)

Классическая логическая игра, тренирующая зрительную память. На игровом поле расположены 16 перевёрнутых карточек с различными изображениями (фруктами и ягодами). 

**Цель игры** — найти все 8 пар одинаковых карточек за минимальное количество ходов.

## 🎮 Правила игры
1. В свой ход вы можете перевернуть любые две карточки.
2. Если изображения на карточках совпадают — они остаются открытыми навсегда.
3. Если изображения отличаются — карточки автоматически перевернутся обратно через 1 секунду. Постарайтесь запомнить, что на них было!
4. Игра заканчивается, когда найдены все 8 пар. 
5. Отслеживайте свои лучшие результаты (по количеству ходов) в «Таблице лидеров».

## 🚀 Как запустить игру

Игра работает прямо в браузере и не требует установки дополнительных программ.

### Открытие локального файла
1. Скачайте файлы игры на свой компьютер.
2. Откройте папку и дважды кликните по файлу `index.html`. Игра откроется в вашем браузере по умолчанию.

## ⚙️ Особенности
* Адаптивный дизайн для комфортной игры на разных устройствах.
* Таблица лидеров сохраняется локально в вашем браузере — вы не потеряете свои рекорды после закрытия вкладки.
* Игра работает полностью автономно без необходимости подключения к интернету.
